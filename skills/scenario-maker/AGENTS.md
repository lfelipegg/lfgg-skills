# Scenario Maker guidance

## Issue tracker

Existing Scenario Maker issues and specs remain in `lfelipegg/scenario-maker-skill`. Before working on those legacy issues or Wayfinder maps, read `docs/agents/issue-tracker.md`. Do not use the old repository for collection-wide work.

## Triage labels

Use the five default triage labels for legacy Scenario Maker issues. Before triaging or applying triage labels, read `docs/agents/triage-labels.md`.

## Domain docs

Keep Scenario Maker's domain context local to this skill: `CONTEXT.md` and `docs/adr/`, created lazily. Before exploring this skill, read `docs/agents/domain.md`. Paths in this guide are relative to `skills/scenario-maker/`, not the collection root.
