# Next Steps

Language for transferring ongoing work between chats without losing its state or
expanding its scope.

## Language

**Handoff**:
A current-state record of a chat's goal, completed work, decisions, evidence, and
remaining work, sufficient for a new chat to resume without the original conversation.
_Avoid_: Transcript, session archive

**Continuation prompt**:
Copy-ready instructions that orient a new chat using the handoff and identify its
first action within the agreed scope.
_Avoid_: Chat summary

**Agreed next step**:
Unfinished work the user has authorized, distinct from a suggestion or an option
that still needs a decision.
_Avoid_: Suggested improvement, automatic follow-up
