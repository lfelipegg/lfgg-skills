# Agent guidance

Terms distinguishing the guidance produced by agent-builder.

## Language

**Root guide**: Repository-wide agent instructions shared across work in the project.

**Local guide**: Agent instructions for meaningful differences within a directory's scope.

**Topic guidance**: Specialized instructions relevant to a subject, such as a language,
testing, or builds, regardless of directory boundaries.
_Avoid_: Local guide when the distinction is subject rather than directory.

**Planning policy**: An established preference governing the content or presentation
of implementation plans.
